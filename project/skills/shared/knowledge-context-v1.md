# 知识独立阅读与关联规范 knowledge-context-v1

本文件只对显式引用它的新提取／审核版本生效，适用于健康&运动、工作事业、学习&能力提升及未分类资料。它不增加来源权限、输出字段、模型阶段或统计口径；既有原文、时间、分类和独立审核要求继续有效。

## 单篇内容要说明自己的来源与范围

- 每份记录和 Wiki 的正文都应让未读本轮对话、导航或其他页面的读者，辨明所述来源名称或资料角色、已知时间／期间和适用范围。名称、时间或范围未知时明确未知，不从文件名、采集时间或执行环境补造。精确来源身份及版本仍由既有 sources 和元数据绑定，不要求在正文重复长哈希。
- “本次”“本轮”“未提供”“没有统计”等判断必须明确指向实际提供的单份来源、选定片段或具体加工范围，不能让单来源限制看起来是在否定整个资料包或全库。原文中的历史状态与本系统当前处理状态分别表达；当前状态仍只取程序提供的已核验 system_facts，不能把导出说明的旧自述改写成现在的事实。
- 同名字段不自动是同一指标。保留所属来源、对象或角色、时间范围、原名称、明示单位、样本／分母及统计口径；不能把不同口径的指标混合、把原始观测与派生统计混为一项，或由相似数值推定等价。资料未提供的字段含义和单位仍未知。

## 关联只使用实际提供且可核对的材料

- 跨文档补充关联只依据输入实际提供的已审核 related 记录及其精确身份、版本和原有口径；来源引用仍须回到实际提供的原文。反馈、路径文字或未读取的全库内容不成为已审核知识，不编造不存在的记录、链接或“其他页面已有”的结论。Wiki 对本轮候选的 record_ids 仍按原输出契约共同受审，不能先把新候选称为已审核。
- 已提供的受审关联确实能补充内容时，说明哪份记录在什么来源／期间／口径下支持什么结论，并保留各自限制，不把关联当作新的独立证据；没有提供关联时只说明当前来源范围，不断言其他资料不存在。即使同主题资料互相关联，单篇仍须直接呈现其主要事实与必要边界，不能只留下跳转链接或“详见其他页面”。
- 审核须分别检查单篇是否自足、已提供记录之间的关系是否真实且口径一致。分解单元只检查实际可见的对象和依据；global 只根据实际提供的最终对象与前序证书核关系，不假称重读缺席的原文、related 或全库内容。可据已有材料修正的范围歧义属于 needs_revision，不自动变成用户待确认事项。
